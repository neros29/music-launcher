# Music Player
This music player will be simple it will have a data base used to store every music file as well as informations such as artist, album, playlist, and so on. Then you can create a custom playlist by choosing which things from which catgories to include the playlist. This will be done thorugh a simple search bar the search bar will allow you to serach through premade playlist albums as well as indivdule songs or curate your own playlist by simply playing all that meet the search querey then the app will send via ipc socket the data to a runnning mpv instinces. I will also add fuzy search to to both allow for autio complite for the catgories such as if you do album: the next work you can auto complte using fuzzy search allowing you to easly find the album you are looking for. You can also chain these catgories so you can sort your music such as using and or and not on the catgorie choice. As well as doing stuff like shuffleing the playlist or playing it in the order already defined if there is no defined order it autmaticly orders it in alphabetical order. You can load premade playlist in using m3u files or json files. You can also save a playlist using that you create using a save playlist options in the ui. The ui will consist of only a search bar. You can provided options and catgoires in this search bar using custom syntax as well as use keybinds to do stuff like play playlist shuffle play playlist or save playlist. The ui will be built using my own custom c++ tui as this is a great usecase for it.
